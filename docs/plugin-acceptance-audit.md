## Acceptance limits

User executables run with the OS user's filesystem/network privileges. Host grants govern host-supplied data and accepted effects; they are not an OS sandbox. External side effects cannot be made exactly once by the host. OS acceptance does not establish notification presentation, and synthetic model/audio tests do not establish live provider or speech quality. macOS was the native platform exercised; other platform integrations may report unavailable. Release signing, notarization and a public marketplace remain separate work.

The normal app and service have not been replaced or restarted. The final isolated native client, both synthetic browser tabs and three newly created test daemons were closed. All test recording/capture sessions are stopped; the preexisting synthetic fixture was preserved. Evidence artifacts live under the ignored `.local/f44-*-verification.json` files; [plugin documentation](plugins.md) describes the public contracts and commands.
